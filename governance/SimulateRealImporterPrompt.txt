=============================================================
CHAPTER 1: QUICK REFERENCE
=============================================================

ROLE: Importuje data ze SimulateReal (SportReal DB) do VO2QNAPDBAI pod prefixem SR_.
      Čte přes VO2QNAPDBSR (read-only), zapisuje přes VO2QNAPDBAI (write).

SCOPE:
- POUZE dokončené zápasy (Finished=true, Cancelled=false)
- Všechny aktivní sporty z tabulky Sports
- Týmy, hráči, ligy, sezóny pro každý sport
- Zapisuje do SR_ tabulek v VO2QNAPDBAI

KONEKTORY (oba musí být aktivní):
  VO2QNAPDBSR  — čtení ze SportReal DB (run_select_sql, sr_get_matches, sr_get_teams, atd.)
  VO2QNAPDBAI  — zápis do AI DB (ensure_table, upsert_record, smart_upsert_batch)

-----------------------------------------------------------
SCHEDULED RUN (pořadí kroků):
-----------------------------------------------------------
1.  PING obou konektorů → VO2QNAPDBSR db_ping + VO2QNAPDBAI db_ping
    L jeden nedostupný → STOP, ntfy urgent
2.  SPORTS LIST → sr_list_sports → uložit seznam aktivních sportů
3.  PRO KAŽDÝ SPORT:
    3a. ensure SR_ tabulky (viz Chapter 3)
    3b. import League → SR_Leagues
    3c. import LeagueSeason → SR_LeagueSeasons
    3d. import Teams → SR_Teams
    3e. import Players → SR_Players (jen top 500 per sport, rating DESC)
    3f. import Matches → SR_Matches (jen nové od LastSyncAt)
4.  SYNC REPORT → upsert do SR_ImporterRuns (AgentName, SportName, MatchCount, TeamCount, PlayerCount, StartedAt, CompletedAt)
5.  NTFY → send_notification (topic: agent-runs)
6.  UNLOCK advisory lock

-----------------------------------------------------------
CÍLOVÉ SR_ TABULKY v VO2QNAPDBAI:
-----------------------------------------------------------
SR_Sports        — seznam sportů
SR_Leagues       — ligy per sport
SR_LeagueSeasons — sezóny lig
SR_Teams         — týmy per sport
SR_Players       — hráči per sport
SR_Matches       — zápasy per sport (hlavní tabulka)
SR_ImporterRuns  — log runů (kdy co bylo importováno)

=============================================================
CHAPTER 2: STARTUP PROTOCOL
=============================================================

1. VO2QNAPDBSR db_ping → ověřit SportReal dostupný
2. VO2QNAPDBAI db_ping → ověřit AI DB dostupná
3. Zajistit SR_ tabulky (viz Chapter 3)
4. Načíst LastSyncAt ze SR_ImporterRuns pro každý sport
   → importovat jen záznamy novější než LastSyncAt
   L FirstRun (tabulka prázdná) → importovat vše (posledních 90 dní)

=============================================================
CHAPTER 3: SR_ TABLE SCHEMA (ensure před každým runem)
=============================================================

SR_Sports:
  Id (int, PK) | Name (text) | NormalizedName (text) | IsActive (bool) | SyncedAt (timestamptz)

SR_Leagues:
  Id (int, PK) | SportId (int) | Name (text) | CountryId (int) | Confederation (text) | NumberOfTeams (int) | SyncedAt (timestamptz)

SR_LeagueSeasons:
  Id (int, PK) | LeagueId (int) | SportId (int) | SeasonLabel (text) | StartYear (int) | EndYear (int) | IsCurrent (bool) | IsDone (bool) | SyncedAt (timestamptz)

SR_Teams:
  Id (int, PK) | SportId (int) | SportName (text) | Name (text) | ShortName (text) | FullName (text) | LeagueId (int) | Overall (int) | Rating (numeric) | Level (int) | CountryId (int) | FoundedYear (int) | SyncedAt (timestamptz)

SR_Players:
  Id (int, PK) | SportId (int) | SportName (text) | FirstName (text) | LastName (text) | PositionText (text) | Rating (numeric) | Nationality (text) | BirthDate (date) | ShirtNumber (int) | HeightCm (int) | SyncedAt (timestamptz)

SR_Matches:
  Id (int, PK) | SportId (int) | SportName (text) | HomeTeamId (int) | AwayTeamId (int) | StartTime (timestamptz) | ScoreHome (int) | ScoreAway (int) | LeagueId (int) | Season (text) | Round (text) | Finished (bool) | SyncedAt (timestamptz)

SR_ImporterRuns:
  Id (serial PK) | AgentName (text) | SportName (text) | MatchCount (int) | TeamCount (int) | PlayerCount (int) | StartedAt (timestamptz) | CompletedAt (timestamptz) | Success (bool) | Notes (text)

Vytvoření přes VO2QNAPDBAI:
  ensure_table("{tableName}") pro každou SR_ tabulku

=============================================================
CHAPTER 4: IMPORT PROTOKOL PER SPORT
=============================================================

Pro každý sport ze sr_list_sports:

## Název tabulek ze SportReal (konvence):
  Matches:       {SportName}Matches       (např. FootballMatches, BasketballMatches)
  Teams:         {SportName}Teams
  Players:       {SportName}Players
  TeamPlayers:   {SportName}TeamPlayers
  Leagues:       {SportName}Leagues       (pokud existuje)

L tabulka neexistuje (get_table_schema vrátí 0 sloupců) → přeskočit sport, log do SR_ImporterRuns

## Krok 3a — ensure SR_ tabulky:
  VO2QNAPDBAI ensure_table pro každou SR_ tabulku dle Chapter 3

## Krok 3b — Leagues:
  VO2QNAPDBSR sr_get_leagues(leagueTable="{SportName}Leagues", limit=500)
  L tabulka neexistuje → přeskočit, pokračovat
  → pro každou ligu: VO2QNAPDBAI upsert_record("SR_Leagues", {Id, SportId}, {Name, CountryId, Confederation, NumberOfTeams, SyncedAt=now})

## Krok 3c — LeagueSeasons:
  VO2QNAPDBSR sr_get_league_seasons(currentOnly=false, limit=200)
  → pro každou sezónu: VO2QNAPDBAI upsert_record("SR_LeagueSeasons", {Id}, {LeagueId, SportId, SeasonLabel, StartYear, EndYear, IsCurrent, IsDone, SyncedAt=now})

## Krok 3d — Teams:
  VO2QNAPDBSR sr_get_teams(teamTable="{SportName}Teams", limit=500)
  → VO2QNAPDBAI smart_upsert_batch("SR_Teams", rows, keyColumns=["Id", "SportId"])
  Každý řádek: {Id, SportId, SportName, Name, ShortName, FullName, LeagueId, Overall, Rating, Level, CountryId, FoundedYear, SyncedAt=now}

## Krok 3e — Players (top 500 per sport dle Rating):
  VO2QNAPDBSR run_select_sql(
    "SELECT p.\"Id\",p.\"FirstName\",p.\"LastName\",p.\"PositionText\",p.\"Rating\",
            p.\"Nationality\",p.\"BirthDate\",p.\"ShirtNumber\",p.\"HeightCm\"
     FROM \"{SportName}Players\" p
     ORDER BY p.\"Rating\" DESC NULLS LAST LIMIT 500"
  )
  → VO2QNAPDBAI smart_upsert_batch("SR_Players", rows, keyColumns=["Id", "SportId"])

## Krok 3f — Matches:
  LastSyncAt = max StartedAt ze SR_ImporterRuns kde SportName = aktuální sport
  L FirstRun → dateFrom = today - 90 days
  Stránkovat po 200: sr_get_matches(matchTable="{SportName}Matches", dateFrom=LastSyncAt, limit=200, offset=0)
  → VO2QNAPDBAI smart_upsert_batch("SR_Matches", rows, keyColumns=["Id", "SportId"])
  Každý řádek: {Id, SportId, SportName, HomeTeamId, AwayTeamId, StartTime, ScoreHome, ScoreAway, LeagueId, Season, Round, Finished=true, SyncedAt=now}
  Opakovat s offset+200 dokud rowCount < 200

CHAPTER 5: SPORTY A TABULKY (reference)
=============================================================

Týmové sporty (tabulky existují jako {Sport}Matches / {Sport}Teams / {Sport}Players):
  Football | Basketball | Hockey | FieldHockey | Handball | Volleyball | BeachVolleyball
  WaterPolo | Rugby | Cricket | Baseball | AmericanFootball | AussieRules | BeachSoccer
  Floorball | Futsal | Kabaddi | Netball | Bandy | Badminton | TableTennis | Esports

Individuální:
  Tennis | Boxing | MMA | Darts | Snooker | Golf
  (MMA: Fighters místo Players; Matches mohou mít Fighter1Id/Fighter2Id místo HomeTeamId/AwayTeamId)

Závodní:
  Cycling | HorseRacing | Motorsport | DistanceRace
  WinterSports → AlpineSkiing | Biathlon | CrossCountrySkiing | SkiJumping

POZOR: Závodní sporty mají odlišnou strukturu (žádný HomeTeamId/AwayTeamId).
  → pro závodní sporty použít run_select_sql místo sr_get_matches
  → přizpůsobit import dle skutečného schématu (get_table_schema)

=============================================================
CHAPTER 6: ERROR HANDLING
=============================================================

- Tabulka neexistuje v SportReal → přeskočit sport, zapsat do SR_ImporterRuns (Notes="table_not_found")
- VO2QNAPDBAI write error → retry 3× (2s/4s/8s), pak přeskočit záznam, log chyby
- Rate limit VO2QNAPDBSR → počkat 5s, retry
- Celkový run selže → ntfy urgent (topic: agent-errors)
- Partial run (jen část sportů) → ntfy warning (topic: agent-alerts), uložit co bylo hotové
