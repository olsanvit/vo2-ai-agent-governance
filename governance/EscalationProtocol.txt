=============================================================
ESCALATION PROTOCOL — v1.1.0
=============================================================
Tento soubor definuje standardni postup pro eskalaci neopravitelnych
problemu z cloud Claude rutin do CloudFixQueue (AIDB).
Nacita se jako soucást Prompt Cache Protocol (krok 2b).
Zdrojovy soubor: EscalationProtocol.txt
=============================================================

## Kdy eskalovat

Eskaluj do CloudFixQueue kdyz:
- Problem byl detekovan, ale NENI opravitelny v cloud sandboxu
- Priklady: db_unreachable, SSH pristup, QNAP/lokalni sit, readiness_degraded,
  expired credentials ktere nelze obnovit automaticky, fyzicky pristup k serveru

Neeskaluj:
- Problemy ktere jsi uspesne opravil
- Docasne chyby (timeout, rate limit) — zkus znovu
- Nejasnosti — zkus zjistit vice informaci nejdrive

## fix_type pravidla

fix_type = local:
  - Problemy vyzadujici SSH na QNAP (192.168.60.221)
  - db_unreachable (PostgreSQL na pg16)
  - readiness_degraded (kontejner nespusteny)
  - Lokalni sit, VPN, fyzicky pristup

fix_type = cloud:
  - GitHub CI selhani resitelne jinym cloud agentem
  - API token obnoveni (kdyz lze pres web/API)
  - Cloud service konfigurace

## Eskalacni postup

Pro kazdy neopravitelny problem pouzij mcp__AIDB__upsert_record:
  table: CloudFixQueue
  criteria: { request_id: "<uuid4>" }
  data:
    fix_type:       "local" nebo "cloud"
    source_routine: "<nazev teto rutiny>"
    service:        "<nazev sluzby>"
    repo:           "<repo nebo ''>"
    problem:        "<strucny popis>"
    tried:          "<co jsi zkousel>"
    severity:       "high" / "medium" / "low"
    status:         "pending"
    request_id:     "<uuid4>"

Pote posli notifikaci (lidska viditelnost):
  mcp__AIDB__send_notification
    topic: "agent-alerts"
    title: "Fix needed — <fix_type>"
    message: "<source_routine>: <problem> (severity: <severity>)"

POZOR: ntfy.vo2info.cz neni dostupny z cloud sandboxu pres curl.
Veskera komunikace probiha pres AIDB MCP konektor.

# Priklady:
#   upsert CloudFixQueue: fix_type=local, source=daily-agent-error-monitor,
#     service=pg16, repo='', problem='db_unreachable', tried='ping', severity=high
#   upsert CloudFixQueue: fix_type=cloud, source=daily-project-error-monitor,
#     service=SimulateReal, repo=olsanvit/SimulateReal, problem='CI fail build',
#     tried='gh run rerun', severity=medium

## Integrace do rutiny

V KROK 1 (Governance Check) pridej nacitani tohoto protokolu:
  curl -s https://raw.githubusercontent.com/olsanvit/vo2-ai-agent-governance/main/governance/EscalationProtocol.txt

V poslednim KROKU rutiny (Eskalace):
  Pro kazdy detakovany a neopraveny problem zavolej mcp__AIDB__upsert_record
  s patricnymi argumenty dle sekce "Eskalacni postup" vyse.
